# Roadmap

Versions before 1.0.0 are previews: they may still change. Plans can change too; this list shows the direction, not promises or dates.

| Version | Planned |
| --- | --- |
| 0.5 (released) | Phone scanner: live camera, photo mode, GS1 checking, copy and share, history |
| 0.6 | Hard-to-read codes: more reader settings and retries. On a PC: paste a picture, drag and drop files, read many files at once |
| 0.7 | HIBC and other health-industry content; batch scanning with CSV export |
| 0.8 | Expected structures (check that codes contain what they should); PDF scan reports |
| 0.9 | A built-in self-test with a report; a package for running the app on your own server |
| 1.0 | First stable release. From then on, every release also stays available, unchanged, at its own address |
| Later | Creating barcodes and labels, checking barcodes in label artwork PDFs, testing what handheld scanners send |
